# Sepiddandan AI Studio

نسخه اولیه پنل تحت وب برای ساخت/ویرایش عکس‌های تبلیغاتی محصولات پت‌شاپ با API تصویر OpenAI.

## امکانات
- بارگذاری عکس محصول
- انتخاب سبک تبلیغ
- فیلد نام محصول و متن اختیاری بنر
- تلاش برای حفظ شکل، رنگ، لوگو و بسته‌بندی محصول
- نمایش خروجی و دانلود PNG

## راه‌اندازی روی کامپیوتر

1. Python 3.10 یا جدیدتر نصب باشد.
2. فایل ZIP را استخراج کنید.
3. در پوشه برنامه، ترمینال/Command Prompt را باز کنید.
4. وابستگی‌ها را نصب کنید:

   ```bash
   pip install -r requirements.txt
   ```

5. برنامه را اجرا کنید:

   ```bash
   streamlit run app.py
   ```

6. صفحه‌ای در مرورگر باز می‌شود. کلید API را در نوار کناری وارد کنید.

## نکات مهم
- کلید API را داخل کد ننویسید و در اختیار دیگران نگذارید.
- استفاده از API ممکن است هزینه جداگانه داشته باشد؛ اشتراک ChatGPT لزوماً شامل اعتبار API نیست.
- اگر مدل انتخاب‌شده در حساب شما در دسترس نیست، مدل دیگری را انتخاب کنید.
- مدل تصویر ممکن است نوشته‌های ریز، لوگوها یا جزئیات بسته‌بندی را دقیق حفظ نکند. خروجی را قبل از انتشار بررسی کنید.
- این نسخه روی کامپیوتر شما اجرا می‌شود؛ برای استفاده عمومی از اینترنت، باید روی یک سرویس میزبانی امن مستقر شود و مدیریت کلیدها/هزینه‌ها به‌درستی انجام شود.
- این نسخه به سایت فروشگاه متصل نیست و انتشار خودکار انجام نمی‌دهد.
